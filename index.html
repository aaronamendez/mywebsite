								Main quest
								 Pilot approved · AZ
							

							
evvAI

							
Builder · Next.js · Third-party presence verification

							

								Medicaid behavioral health runs on trust, and claims fraud costs a lot of money. evvAI proves a
								resident was actually there before a claim gets paid. The design rule is simple: the facility
								is an untrusted party, so nothing they type counts as verified presence.
							

							
    
								
  • Kiosk check-in with three-angle live capture, head tracked on-device with MediaPipe
    • 
								
  • Face match via AWS Rekognition, kiosks bound to passkeys (WebAuthn)
    • 
								
  • Append-only, hash-chained attestations, signed chain seals every night
    • 
								
  • Claims engine scores CSV / 837P lines; Claude reviews pseudonymised data as a second opinion
    • 
							

							

								Next.jsTypeScriptPrismaPlanetScaleAuth.jsRekognitionClaudeVercel

								 Autopilot
							
    
							
    Project Ultron
    
							
    Multi-agent orchestration lab · Claude Agent SDK
    
							
    
								I built this to learn how to get AI agents to work together while I sleep. It's a pixel
								space station where every agent is a sprite walking between rooms: a scout researches the
								market, an artist designs, a critic rejects weak work and sends it back, and a shopkeeper
								lists what passes on Etsy. Making money is a side effect. The point is the coordination.
							
    
							
      
								
    • Nine roles, each one a prompt, a station and a set of tools
      • 
								
    • A critic-and-revise loop, resumable runs, crash retries
      • 
								
    • Daily market strategist, autopilot with cost and publish caps
      • 
								
    • Every agent streams events over SSE; anything that can POST JSON can join
      •
