# aaronamendez.com

My personal website. Next.js (App Router), deployed on Netlify.

```bash
yarn install
yarn dev      # http://localhost:3000
yarn build
```

- Copy that changes often (achievements, career log, loadout) lives in `lib/content.ts`.
- Page interactivity (canvas demos, visitor achievements, easter eggs) is in `lib/site-effects.js`.
- The 2021 site is still playable at `/legacy/index.html`.
